What is it

A complete commerce engine, delivered over REST

Astro Stores provides every primitive you need to run an online store such as products, inventory, carts, orders, customers, and payments..Via a clean, predictable REST API.

Whether you're building a storefront from scratch, migrating off a monolithic platform, or wiring commerce into an existing app, the API fits around your stack rather than the other way around.

Astro Stores REST API
# Base URL
https://api.astrostores.io/v1

# Authenticate with a bearer token
Authorization: Bearer {your_api_key}

# Resources available
GET /products
POST /carts
POST /orders
GET /customers/:id
GET /inventory
POST /payments/checkout

Capabilities

Everything the API covers

🛍

Product Catalog

Create and manage products with variants, attributes, media, pricing, and categories. Supports digital and physical goods.

📦

Inventory

Track stock levels per variant and location. Reservation hooks keep inventory accurate during checkout.

🛒

Cart & Checkout

Persistent carts tied to sessions or customers. Line item management, discount codes, and shipping quotes.

🧾

Orders

Full order lifecycle — placed, fulfilled, shipped, returned. Webhooks fire at every state transition.

👤

Customers

Account creation, address books, order history. Supports guest checkout alongside registered flows.

💳

Payments

Provider-agnostic payment intents. Bring your own Stripe, Paystack, or Flutterwave keys — we stay out of the way.

How it works

From API key to live store

01

Generate your API key

Create a store workspace and get a scoped API key. Separate keys for test and production environments.

02

Explore in the playground

Use the interactive OpenAPI docs to send live requests against a sandbox store — no setup required.

03

Build your storefront

Call the REST endpoints from any language, framework, or edge runtime. JSON in, JSON out.

04

Go live

Swap to a production key. Wire up webhooks for order events, inventory alerts, and payment confirmations.
